HALL 03 • VISUAL STORYTELLING

ห้องนิทรรศการและการแปรรูปความรู้ 5 ขั้นตอน

สถาปัตยกรรมการแปลงข้อมูลจดหมายเหตุสู่โครงสร้างสากล: Excavate → Decode → Retell → Connect → Apply

แผนภาพไอโซเมตริก: DISCOVER • UNDERSTAND • LEARN • REASON • APPLY
STAGE 01: EXCAVATE (ขุดค้น & คัดสรร)
สำรวจคลังจดหมายเหตุ ประวัติศาสตร์ และวิทยาการไทย พร้อมตรวจสอบความน่าเชื่อถือทุกจุด
STAGE 02: DECODE (ถอดรหัสข้อมูล)
แปลงข้อมูลเป็น Entity Nodes, Categories และ Relationships ใน Knowledge Graph Schema
STAGE 03: RETELL (เล่าใหม่ด้วยภาพ)
Visual Storytelling สั้นกระชับ จบใน 3–5 นาที เข้าใจง่ายสำหรับประชาชนทุกวัย
STAGE 04: CONNECT (เชื่อมต่อเครือข่าย)
ระเบิดโครงข่ายข้ามยุคสมัยผ่าน Data Booming Engine แสดงความเกี่ยวโยงของความรู้
STAGE 05: APPLY (นำไปใช้จริงในชีวิต)
ปิดท้ายทุกนิทรรศการด้วยการ์ด Everyday Takeaway ที่นำไปปฏิบัติได้ทันที
